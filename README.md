# Hasta-Kala Shop 🎨

Hasta-Kala Shop is a Micro-Sales Analytics and Billing application designed for micro-entrepreneurs and artisans, such as banana fiber craft makers. It helps solve the problem of dead stock by providing simple, data-driven insights into sales and inventory.

## 🌟 The Problem

Many artisans struggle with inventory tracking. Without proper sales records, they cannot identify which colors, designs, or product types are the best sellers. This often leads to overproduction of less popular items, stock shortages of popular ones, wasted materials, and reduced profit.

## 🚀 The Vision

Hasta-Kala Shop gives micro-entrepreneurs the power of business intelligence in a simple app that works like a digital ledger. It helps them track sales, manage inventory, and make better business decisions.

## ✨ Key Features

- ⚡ Quick Bill: Fast bill entry with large visual icons. Select a product, choose a variant, and save the sale in seconds.
- 📊 Best Seller Dashboard: Real-time sales visualization using MPAndroidChart with Pie and Bar charts.
- ⚠️ Stock Alert: Automatically tracks inventory and highlights items that are running low.
- 💰 Income Log: Maintains a detailed sales history with filters like This Week and This Month.

## 🛠️ Technical Stack

- UI: Jetpack Components, ViewBinding, and Material Design 3
- Database: Room DB for offline-first local storage
- Architecture: MVVM with Repository pattern
- Visualization: MPAndroidChart
- Asynchronous Processing: Kotlin Coroutines and Flow

## 🎯 Impact Goals

- Business Intelligence: Helps artisans make data-driven decisions
- Waste Reduction: Reduces production of unsold goods
- Growth Mindset: Encourages small businesses to track and improve their progress

## 📱 Screen Flow

1. Billing: Tap a product icon → Select variant → Save
2. Analytics: View sales charts on the dashboard
3. Inventory: Check alerts for restock needs
4. History: Filter income log by time period

## ⚙️ Installation

1. Clone the repository
2. Open the project in Android Studio
3. Sync Gradle
4. Run the app on an emulator or Android device
